
Paso 1 Inicia todos los servicios:
docker compose up -d

Paso 2 Comprueba que los contenedores estén funcionando:
docker compose ps

Paso 3 Este paso es importante por el problema de Nginx que acabamos de solucionar.
Recarga su configuración después de iniciar todos los servicios:
docker exec gestion-desarrollo-software-equipo01-frontend-1 nginx -s reload

Paso 4 Abre tu navegador y entra en:
http://localhost:8080

Paso 5 Detener docker
docker compose down
